โครงสร้าง Thread

Main Thread (Tkinter)
  ├── _pump_hotkeys()  ← polling every 20ms
  ├── _heartbeat()     ← logging every 5 min
  └── UI event loop

HotkeyServer Thread  (Message-only Win32 window)
  ├── GetMessageW loop
  ├── RegisterHotKey / UnregisterHotKey  (owner-thread only)
  └── events.put(cb)  →  Tk thread drains via SimpleQueue

Audio / STT Thread  (daemon)
  ├── sounddevice InputStream callback  →  _audio_chunk[]
  └── STT engine  →  self.after(0, _finish_text)

Polish Thread  (daemon, per-request)
  └── POST Groq API  →  self.after(0, _apply_polish)

RegisterHotKey (x64) — ทำไมถึงใช้แทน keyboard hook?

ไลบรารี keyboard ใช้ WH_KEYBOARD_LL hook ซึ่งต้องการให้โปรแกรมมี message pump ที่รวดเร็วพอ แต่เมื่อโปรแกรมถูก minimize หรือถูก Windows throttle, hook จะหยุดรับ event

RegisterHotKey เป็น kernel-level API ที่ส่ง WM_HOTKEY ตรงไปยัง window message queue โดยไม่สนใจสถานะโฟกัส — hotkey จึงทำงานได้แม้ขณะเล่นเกม, ดูหนัง, หรือ minimize โปรแกรม

⚠️ ข้อจำกัด: RegisterHotKey ต้องเรียกจาก thread ที่เป็นเจ้าของ window เท่านั้น — โค้ดจึงใช้ SendMessageW เพื่อ marshal call ข้าม thread ก่อนเสมอ

Hotkey Watchdog

ทุก 20ms _pump_hotkeys() ตรวจสอบว่า _HotkeyServer ยังมีชีวิตอยู่หรือไม่ ถ้า thread ตายจะสร้าง server ใหม่อัตโนมัติ (cooldown 5 วินาที)

การ์ดข้อความ (Segment Cards)

แต่ละครั้งที่อัดเสียงจะสร้างการ์ดใหม่ การ์ดมีฟีเจอร์ดังนี้:

  • คลิกการ์ด = copy ข้อความทั้งใบไปยัง clipboard
  • แก้ไขข้อความโดยตรงภายในการ์ด
  • ปุ่ม ✨ = AI Polish (Groq)
  • ปุ่ม ↑ ↓ = เรียงลำดับการ์ด
  • ปุ่ม 🗑 = ลบการ์ด
  • Checkbox = เลือกหลายการ์ดพร้อมกัน แล้ว copy รวม

แถบรวม (Combined Bar)

แสดงข้อความจากทุกการ์ดที่มีอยู่ต่อกันในแถบด้านล่าง กดเพื่อ copy ทั้งหมดด้วยคลิกเดียว

AI Polish (Groq)

ส่งข้อความไปยัง Groq API (llama-3.1-8b-instant) พร้อม prompt ที่สั่ง:

  1. ลบคำสร้อย เช่น "เอ่อ" "อ่า" "อืม" "แบบว่า"
  2. เก็บเฉพาะเวอร์ชันล่าสุดเมื่อพูดผิดกลางประโยค
  3. จัดประโยคให้อ่านง่าย แต่ห้ามเพิ่มเนื้อหาใหม่

ผลลัพธ์ถูก copy ไปยัง clipboard ทันที

F9 Direct Dictation

  1. กด F9 ขณะโฟกัสอยู่ที่แอปเป้าหมาย (Word, browser, Discord ฯลฯ)
  2. โปรแกรมจดจำ window handle ของแอปนั้น เริ่มอัดเสียง
  3. กด F9 อีกครั้ง → หยุดอัด
  4. ข้อความถูก paste เข้าแอปเดิมอัตโนมัติผ่าน Ctrl+V
💡 clipboard เดิมจะถูกเก็บและคืนค่ากลับหลัง paste เสร็จ

Edge Tab (ย่อเป็นแถบ)

เมื่อกด F8 หรือคลิกปุ่ม collapse หน้าต่างจะซ่อนและแสดงแถบบาง ๆ ที่ขอบหน้าจอ:

  • ลูกศร (ขยาย) + ไอคอน 🔒/🔓 (Auto-expand on/off)
  • เมื่อ 🔓: วาง mouse เหนือแถบ 350ms → ขยายอัตโนมัติ
  • เมื่ออัดเสียงอยู่: แถบสีเขียวจะแสดงที่ด้านบนของ edge tab
  • Hover zone ขยาย ±150px รอบแถบเพื่อรับ mouse events ได้ง่ายขึ้น

แถบรวม (Combined Bar)

แถบสีเข้มที่ด้านล่างสุดของแผงซ้าย รวมข้อความจากทุกการ์ดต่อกัน:

  • คลิกแถบรวม = copy ข้อความทั้งหมดทุกการ์ดด้วยคลิกเดียว
  • ข้อความภาษาไทยต่อกันโดยไม่มี space / ภาษาอังกฤษมี space คั่น
  • อัปเดตอัตโนมัติทุกครั้งที่เพิ่มหรือแก้ไขการ์ด

เลือกหลายการ์ดพร้อมกัน

  • ติ๊ก Checkbox ที่มุมซ้ายบนของแต่ละการ์ดเพื่อเลือก
  • กดปุ่ม 📋 Copy ที่เลือก ที่ toolbar ด้านบน → copy เฉพาะการ์ดที่ติ๊กไว้ต่อกัน
  • ใช้เมื่อต้องการรวมเฉพาะบางช่วงของการบันทึก

Level Meter (แถบวัดเสียง)

  • แถบสีแสดงระดับเสียงไมโครโฟน real-time ขณะอัดเสียง
  • ช่วยตรวจสอบว่าไมโครโฟนรับเสียงได้หรือไม่ก่อนพูด
  • ถ้าแถบไม่ขยับเลย = ไมโครโฟนไม่ทำงาน ให้ตรวจ Windows Sound Settings

System Tray

เมื่อโปรแกรมเปิดอยู่จะมีไอคอน 🎤 ที่ System Tray (มุมขวาล่างของ taskbar):

  • คลิกขวา → แสดง/ซ่อน — เรียกหน้าต่างกลับมา
  • คลิกขวา → วิธีใช้ — แสดงสรุปคีย์ลัด
  • คลิกขวา → ออกจากโปรแกรม — ปิดโปรแกรมสมบูรณ์
  • ดับเบิลคลิกไอคอน = แสดง/ซ่อนหน้าต่างทันที

Vocab Placeholder Tokens (ABC / ABC1 / ABC2)

เมื่อเพิ่มคำใน Vocab โดยเว้นช่อง "คำที่ถอดผิด" ว่าง คำนั้นจะกลายเป็น Placeholder Token ที่คลิกได้ในการ์ด:

  1. พูดข้อความที่มีคำ placeholder เช่น "ABC" หรือ "ABC 1"
  2. STT ถอดออกมาแล้ว token นั้นจะมีปุ่มสีน้ำเงินคลิกได้ในการ์ด
  3. คลิก token ในการ์ด → token ถูก "เลือก" (highlight)
  4. คลิกคำใน Vocab list ด้านขวา → แทนที่ token ด้วยคำนั้นทุกจุดในการ์ด
💡 ใช้สำหรับคำที่ไม่แน่ใจตอนพูด เช่น ชื่อโปรแกรม ชื่อคน — พูด "ABC" แล้วแทนทีหลัง

การตั้งค่า

ไฟล์ speech_panel_config.json

โปรแกรมบันทึกการตั้งค่าทั้งหมดใน JSON file นี้ อัปเดต atomic (เขียน .tmp แล้ว replace) เพื่อป้องกันไฟล์เสียหายเมื่อโปรแกรมปิดกะทันหัน

{
  "mode":             "free",            // โหมด STT: free | whisper | vosk | gcloud
  "stt_engine":       "google",          // เอนจิ้นภายใน
  "auto_collapse":    false,             // ย่อ panel อัตโนมัติเมื่อเปิดโปรแกรม
  "auto_expand":      false,             // ขยาย panel เมื่อ hover edge tab
  "locked":           true,              // ล็อคตำแหน่ง panel
  "hotkey_toggle":    "ctrl+shift+space",
  "hotkey_collapse":  "f8",
  "hotkey_record":    "f10",
  "hotkey_dictate":   "f9",
  "gemini_api_key":   "gsk_...",         // Groq API Key (ชื่อ field เดิมจาก Gemini era)
  "max_segments":     20,                // 0 = ไม่จำกัด
  "vocab_tabs": {
    "1": [ {"wrong": "", "right": "GitHub"} ],
    "2": [ {"wrong": "ขอโค้ด", "right": "Claude Code"} ],
    "3": []
  },
  "vocab_active_tab": "1"
}
⚠️ ถ้าไฟล์ config เสียหาย (JSON ไม่ valid) โปรแกรมจะสำรองไฟล์เดิมเป็น .corrupt และเริ่มด้วยค่าเริ่มต้น

คำศัพท์ Vocab Tabs

แผง Vocab (ฝั่งขวา) มี 3 แท็บ แต่ละแท็บเก็บรายการคู่ คำผิด → คำที่ถูก

วิธีการทำงาน

  • Longest-match first: คำที่ยาวกว่าจะถูกเปรียบเทียบก่อน ป้องกัน false match
  • Space-tolerant: STT มักแยก "123" เป็น "1 2 3" — regex จับ whitespace ระหว่างตัวอักษรได้
  • Case-insensitive: ตัวพิมพ์ใหญ่/เล็กไม่สำคัญ
  • ถ้าช่อง "คำที่ถอดผิด" ว่างเปล่า = เพิ่มคำในรายการเสนอแนะ (placeholder ที่คลิกได้)

เพิ่มคำใหม่

  1. คลิกปุ่ม + เพิ่มคำ ในแผง Vocab
  2. ช่อง "คำที่ถอดผิด" — ใส่คำที่ STT มักเข้าใจผิด (เว้นว่างได้)
  3. ช่อง "คำที่ถูกต้อง" — ใส่คำที่ต้องการแทน
  4. กด บันทึก

วิธีใช้ทีละขั้นตอน

ติดตั้งครั้งแรก

  1. ติดตั้ง Python 3.11+ จาก python.org — ต้องติ๊ก "Add Python to PATH"
  2. ดับเบิลคลิก install.bat — รอจนหน้าต่างแสดง "ติดตั้งเสร็จแล้ว!"
  3. ดับเบิลคลิก start_speech_panel.bat เพื่อเปิดโปรแกรม
  4. (ตัวเลือก) กด ⚙️ → ใส่ Groq API Key เพื่อใช้ AI Polish

ใช้งานประจำวัน

  1. เปิดโปรแกรมด้วย start_speech_panel.bat
  2. กด F10 หรือปุ่ม 🎤 เพื่อเริ่มอัดเสียง — แถบ Level Meter จะขยับ
  3. พูดแล้วกด F10 อีกครั้ง → ข้อความแสดงในการ์ดใหม่ทันที
  4. คลิกการ์ดเพื่อ copy หรือกด ✨ เพื่อ Polish ด้วย AI
  5. กด F8 เพื่อย่อแผงเป็น edge tab เมื่อไม่ต้องการ

Dictate ใส่ Word / Discord / LINE / ฯลฯ

  1. คลิกในพื้นที่ที่ต้องการพิมพ์ (Word, chat box, search bar…)
  2. กด F9 — โปรแกรมเริ่มอัดเสียงทันที
  3. พูดข้อความที่ต้องการ
  4. กด F9 อีกครั้ง → ข้อความถูก paste เข้าแอปเดิมอัตโนมัติ
💡 clipboard เดิมถูกบันทึกไว้และจะถูกคืนหลัง paste เสร็จ ไม่ต้องกังวลว่าจะหาย

ใช้ Vocab แก้คำถอดผิด

  1. อัดเสียงตามปกติ → ข้อความปรากฏในการ์ด
  2. ถ้า STT ถอดคำผิด เช่น "ขอโค้ด" แทนที่จะเป็น "Claude Code"
  3. เปิดแผง Vocab ฝั่งขวา → เพิ่มคู่ "ขอโค้ด" → "Claude Code"
  4. ครั้งต่อไปที่พูด "Claude Code" โปรแกรมจะแก้ให้อัตโนมัติ

ใช้ Placeholder Token (ABC/ABC1)

  1. เพิ่มคำใน Vocab โดยเว้นช่อง "คำที่ถอดผิด" ว่าง → ใส่แค่ "คำที่ถูกต้อง"
  2. ตอนพูด ใช้คำว่า "ABC" หรือ "ABC 1" เป็น placeholder
  3. ในการ์ดจะมีปุ่ม token สีน้ำเงิน — คลิกเพื่อ "เลือก" token นั้น
  4. จากนั้นคลิกคำใน Vocab list → คำนั้นแทนที่ token ทุกจุดในการ์ด

Copy ข้อความหลายการ์ดพร้อมกัน

  1. ติ๊ก Checkbox ที่มุมซ้ายบนของการ์ดที่ต้องการ (เลือกได้หลายใบ)
  2. กดปุ่ม 📋 Copy ที่เลือก ที่ toolbar ด้านบน
  3. ข้อความจากทุกการ์ดที่เลือกถูก copy รวมกันไปยัง clipboard

เปิด AI Chat พร้อม copy ข้อความ

  1. อัดเสียงและแก้ไขข้อความในการ์ด
  2. คลิกการ์ดหรือกดปุ่ม Copy เพื่อ copy ข้อความ
  3. เลือก AI ที่ต้องการจาก dropdown ด้านบน (ChatGPT, Claude, Gemini…)
  4. กดปุ่ม → เปิด → browser เปิดหน้า AI นั้น
  5. Paste ข้อความลงใน chat ของ AI

ใช้งานจาก System Tray (เมื่อปิดหน้าต่าง)

  1. กด X เพื่อซ่อนหน้าต่าง — โปรแกรมยังทำงานอยู่เบื้องหลัง
  2. มองหาไอคอน 🎤 ที่ System Tray มุมขวาล่าง taskbar
  3. คลิกขวา → แสดง/ซ่อน หรือกด Ctrl+Shift+Space เพื่อเรียกกลับมา
  4. คลิกขวา → ออกจากโปรแกรม เพื่อปิดสมบูรณ์

แก้ปัญหา

❌ กด F9/F10/F8 แล้วไม่ตอบสนองในเกม

สาเหตุ: hotkey อาจขัดแย้งกับเกม หรือ HotkeyServer thread ตายชั่วคราว

แก้:

  • รอ 5 วินาที — watchdog จะ restart server อัตโนมัติ
  • ลองเปลี่ยน hotkey ใน ⚙️ เป็นปุ่มที่เกมไม่ใช้
  • บางเกมบล็อก keyboard input ของ process อื่น — ลอง run SpeechPanel as Administrator

❌ โปรแกรมปิดตัวเองกะทันหัน

ตรวจสอบ log:

# Python crash log
speech_panel_crash.log

# Native crash (C-level access violation)
native_crash.log

สาเหตุที่พบบ่อย: audio stream ถูกเขียนทับขณะ PortAudio ยังใช้งานอยู่ (แก้ไขแล้วใน v2.0-bugfix-opus)

❌ AI Polish ไม่ทำงาน

  • ตรวจสอบว่าใส่ Groq API Key ใน ⚙️ แล้วหรือยัง
  • Error 429 = เกิน quota 30 req/นาที — รอ 1 นาทีแล้วลองใหม่
  • Error 401/403 = API Key ไม่ถูกต้อง — สร้าง key ใหม่ที่ console.groq.com

❌ โปรแกรมเปิดสองครั้ง / เปิดไม่ขึ้น

SpeechPanel มี single-instance guard ด้วย Windows Mutex

  • ถ้าโปรแกรมเปิดอยู่แล้ว: กด Ctrl+Shift+Space เพื่อแสดง
  • ถ้าเปิดไม่ขึ้นเลย: เปิด Task Manager → ค้นหา python.exe → End Task

❌ ไฟล์ config เสียหาย / โปรแกรมเริ่มใหม่โดยไม่มีการตั้งค่า

หาไฟล์ speech_panel_config.json.corrupt — นั่นคือ backup ของ config ก่อนเสียหาย

# ดูไฟล์ backup
type speech_panel_config.json.corrupt

❌ เสียงไม่ถูกถอด หรือถอดผิดมาก

  • ตรวจสอบว่าไมโครโฟนถูกเลือกใน Windows Sound Settings
  • ลองเปลี่ยนโหมด STT — Whisper ให้คุณภาพดีกว่า Free สำหรับภาษาไทย
  • เพิ่ม Vocab pairs สำหรับคำที่ถอดผิดซ้ำ ๆ

❌ Whisper โหลดนานมาก

model large-v3 ใช้เวลาโหลดครั้งแรก 30-120 วินาที ขึ้นกับ SSD/RAM และ GPU VRAM

เปลี่ยนเป็น medium หรือ small ในโค้ดบรรทัด 52 เพื่อโหลดเร็วขึ้น
