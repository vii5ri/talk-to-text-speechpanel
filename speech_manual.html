ฟีเจอร์

การย่อโปรแกรม / Edge Tab

โปรแกรมสามารถย่อเป็นแท็บเล็กติดขอบจอ เพื่อประหยัดพื้นที่ขณะเล่นเกมหรือทำงาน

วิธีการทำงาน
1
เลือกขอบที่ต้องการ

กดปุ่ม ◀ ▲ ▶ ▼ ใน Header เพื่อเลือกว่าโปรแกรมจะติดขอบไหนของจอ หรือลากโปรแกรมไปใกล้ขอบแล้วปล่อย

2
กดปุ่ม ⊟ เพื่อย่อ

โปรแกรมจะหายไปและมีแท็บเล็กๆ ปรากฏที่ขอบจอ

3
Hover เมาส์ที่แท็บเพื่อขยาย

นำเมาส์ไปชี้ที่แท็บขอบจอ โปรแกรมจะขยายออกมาทันที มีพื้นที่ Hover ล่องหน 150px รอบแท็บเพื่อจับเมาส์ได้ง่ายขึ้น

โหมดการย่ออัตโนมัติ
🖱 ปิด
เมาส์ออกนอกโปรแกรม ไม่ย่อ — ต้องกด ⊟ เองเท่านั้น
🖱 เปิด
เมาส์ออกนอกโปรแกรม ย่อเองอัตโนมัติ — สะดวกขณะใช้งานสลับกับโปรแกรมอื่น
🔒 ล็อค
ล็อคป้องกันการย่อทุกรูปแบบ — แม้กด ⊟ ก็ไม่ย่อ ใช้เมื่อต้องการให้โปรแกรมค้างหน้าจอตลอด
ตั้งค่า

หน้าต่างตั้งค่า STT

กด ⚙️ ในแถบหัวเพื่อเปิด — ใช้ตั้งค่าโหมด Vosk และ Google Cloud

🔌 Vosk — ออฟไลน์ Real-time
1
ดาวน์โหลด Vosk Thai Model

ไปที่ alphacephei.com/vosk/models แล้วดาวน์โหลด vosk-model-small-th-0.15

2
แตก zip แล้วจำ path ของโฟลเดอร์

เช่น C:\vosk-model-small-th-0.15

3
กด "เลือก Folder" ใน ⚙️

เลือก folder ที่แตกไว้ แล้วกด บันทึก — จากนั้นเลือกโหมด 🔌 Vosk ใช้งานได้เลย

☁️ Google Cloud STT — คุณภาพสูง
1
สร้าง Google Cloud Project

ไปที่ console.cloud.google.com → สร้าง Project → เปิดใช้งาน Cloud Speech-to-Text API

2
สร้าง Service Account

IAM & Admin → Service Accounts → สร้างใหม่ → ดาวน์โหลด JSON key

3
กด "เลือก File" ใน ⚙️

เลือกไฟล์ JSON ที่ดาวน์โหลด แล้วกด บันทึก — ฟรี 60 นาที/เดือน

⚠️ ไฟล์ JSON คือ "กุญแจ" เข้า Google Cloud ของคุณ อย่าแชร์หรือ upload ขึ้น GitHub
คีย์ลัด

ปุ่มลัด (Keyboard Shortcuts)

ใช้ได้ทั้งขณะโปรแกรมเปิดอยู่และขณะซ่อนอยู่ใน System Tray

ปุ่มลัด ทำงานอะไร หมายเหตุ
Ctrl + Shift + Space แสดง / ซ่อน หน้าต่าง ใช้ได้ตลอด แม้โปรแกรมจะถูกซ่อนด้วยปุ่ม ─
Space เริ่ม / หยุด อัดเสียง ใช้ได้เมื่อหน้าต่างโปรแกรม Active อยู่
💡 ถ้าโปรแกรมถูกย่อเป็น Edge Tab ให้ hover เมาส์ที่แท็บเพื่อขยายก่อน จากนั้น Space ค่อยใช้งานได้
การติดตั้ง

ติดตั้งในเครื่องใหม่

มี 2 วิธี — แบบ .exe ไม่ต้องติดตั้ง Python, แบบ Python ต้องติดตั้งก่อน

⭐ วิธีที่ 1: แบบ .exe (แนะนำ) — ไม่ต้องติดตั้ง Python
1
Build ในเครื่องที่ติดตั้งโปรแกรมแล้ว

ดับเบิลคลิก build.bat ในโฟลเดอร์โปรแกรม รอจนเสร็จ (ใช้เวลาประมาณ 2-5 นาที)

2
Zip โฟลเดอร์ที่ได้

จะมีโฟลเดอร์ dist\SpeechPanel\ สร้างขึ้น — คลิกขวา → Compress to ZIP

3
ส่ง ZIP ไปยังเครื่องใหม่

ผ่าน USB, Google Drive, หรือ LINE — แตก ZIP แล้วดับเบิลคลิก SpeechPanel.exe ได้เลย

4
ตั้งค่าครั้งแรก (เครื่องใหม่)

กด ⚙️ เพื่อตั้งค่า Vosk path หรือ Google Cloud credentials ถ้าต้องการใช้โหมดนั้น

✅ เครื่องปลายทาง ไม่ต้องติดตั้ง Python, pip, หรือ package ใดๆ ทั้งสิ้น
วิธีที่ 2: แบบ Python (สำหรับนักพัฒนา)
1
ติดตั้ง Python 3.11+

ดาวน์โหลดจาก python.org — เลือก "Add Python to PATH" ขณะติดตั้ง

2
Copy โฟลเดอร์โปรแกรมทั้งหมด

รวมถึง speech_panel.py, speech_panel.ico, requirements.txt

3
ดับเบิลคลิก install.bat

รอจนติดตั้ง package ทั้งหมดเสร็จ (ต้องมีอินเทอร์เน็ต)

4
ดับเบิลคลิก start_speech_panel.bat

เพื่อเปิดโปรแกรม

5
สร้าง Shortcut เพื่อ Pin ใน Start Menu

คลิกขวาที่ start_speech_panel.bat → Create Shortcut → ลาก Shortcut ไปวางใน C:\ProgramData\Microsoft\Windows\Start Menu\Programs\ แล้ว Pin ได้เลย

เปิดตอน Windows เริ่มต้น (Auto-start)

กด ⚙️ ในแถบหัว → จะมีตัวเลือก "เปิดอัตโนมัติตอน Windows เริ่มต้น" — เปิดไว้โปรแกรมจะรันทุกครั้งที่เปิดเครื่อง ไม่ต้องกดเปิดเอง
